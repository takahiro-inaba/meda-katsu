# メダ活 — ビオトープ台帳

メダカやドジョウのいるビオトープを記録する Web アプリ。PC でもスマホでも使えます。
記録はブラウザの `localStorage` に保存され、サーバは使いません。

## 使う

```
open index.html      # macOS
xdg-open index.html  # Linux
```

ビルドもインストールも不要です。ブラウザで `index.html` を開けば動きます。

## 画面の幅で形が変わります

記録するのはビオトープの前、つまりスマホです。狭い画面では次のように組み替わります。

| | PC | スマホ |
|---|---|---|
| ナビ | 左の固定サイドバー | 上部に固定した横スクロールのタブ |
| 表 | 通常の表 | 1 行 1 カード（横スクロールでは操作列に指が届かないため） |
| グラフ | 座標系 760px | 座標系 340px（拡大率を 1 に近づけて目盛りを読める大きさに保つ） |
| 入力欄 | 2〜3 列 | 1 列・文字は 16px（iOS が拡大しないように） |

## できること

| 画面 | 内容 |
|---|---|
| ダッシュボード | 最新の水温、記録から見つけた気づき、生き物の合計、最後の水換えからの日数、水温の推移、最近の作業 |
| 生き物 | 種類・呼び名・導入日・メモの台帳。数は増減の履歴から計算し、合計匹数の推移をグラフで表示 |
| 水質 | 水温と pH の記録、推移グラフ（30日 / 90日 / 全期間）、測定の一覧 |
| 作業ログ | 餌やり・水換え・足し水・掃除・観察の記録を時系列で表示。写真を添付できる |
| 水草・設備 | 水草 / 底床 / 機材を種別ごとに一覧。設置日からの経過日数を表示 |
| 写真 | 撮った写真を月ごとに並べる。定点で撮りためると変化がたどれる |

ビオトープは複数登録でき、サイドバーの選択で切り替えます。記録はビオトープごとに分かれます。

削除は取り消せます（削除後に出るトーストの「元に戻す」）。

### 気づき

ダッシュボードに出る「気づき」は、**記録から機械的に導ける指摘だけ**です。外部のサービスには
何も送りません。オフラインでも動きます。

見ているのは、水温の高さと急変、pH の範囲と振れ幅、水換えの間隔（普段の中央値との比較）、
死亡と繁殖の数、数が長く動いていない生き物、底床の使用年数、記録や写真の途切れです。

どの指摘にも**根拠にした数字を必ず添えています**。数字を見せずに助言だけ出すと、
合っているのか判断できず、そのうち読まれなくなるためです。

### 生き物の数の持ちかた

「いま何匹か」は保存していません。保存しているのは**出来事**だけです。

| 出来事 | 数への効き方 |
|---|---|
| 導入 / 繁殖 | 足す |
| 死亡 / 譲渡 | 引く |
| 数え直し | その数で置き換える |

いまの数は、その生き物の出来事を古い順に積み上げて計算します。数を直接書き換える作りだと
「12匹だったのが今は 8匹」しか残らず、繁殖したのか死んだのかが消えてしまうためです。
ミナミヌマエビのように正確に数えられないものは「数え直し」で実測値に置き換えます。

### 水草・底床・機材の持ちかた

3 つは性質が違いますが「入れた → 使っている → 撤去した」という一生は同じなので、
種別を持つ一つの表で扱います。量は「3株」「20L」「1台」と単位がばらばらなので自由入力です。

撤去したものは削除せず `removedAt` が入り、一覧から外れます（「撤去したものも表示」で見られます）。
何をいつまで使っていたかは、後から効いてくる記録だからです。

### 写真の保存先

写真だけ保存先が違います。

| 中身 | 保存先 | 理由 |
|---|---|---|
| 記録（生き物・水質・ログ） | `localStorage` | 小さく、JSON でそのまま持ち出せる |
| 画像そのもの | `IndexedDB` | `localStorage` は全体で 5MB 程度しかなく、写真 1 枚で使い切る |

取り込むときに長辺 1600px の JPEG へ縮めます（4000×3000 の写真が 30KB 程度になります）。
`IndexedDB` の割り当てはブラウザによりますが数百MB あるため、数千枚は入ります。

## データの持ち出し

サイドバーの「バックアップ / 復元」から、記録を JSON で表示・コピーできます。
別のブラウザでその JSON を貼り付ければ復元できます。

**写真は JSON に含まれません。**容量が大きく、貼り付けで運べないためです。写真はこの端末に残ります。

保存先は開いているブラウザの中だけです。別の端末とは共有されず、ブラウザのデータを消すと記録も消えます。

## 構成

```
index.html                 画面の骨組み
src/app.css                デザイントークンとスタイル（明暗どちらのテーマにも対応）
src/app.js                 状態・保存・描画・グラフ（依存ライブラリなし）
scripts/build-artifact.mjs 1枚のHTMLにまとめて dist/artifact.html を出力
docs/loop-log.md           要求と決定の履歴
```

グラフは SVG を直接組み立てています。水温と pH は別々のグラフです
（ひとつの縦軸に 2 つの尺度を載せると値を読み違えるため）。
系列色は色覚特性を考慮した検証済みの組み合わせを使っています。

## 開発

```
node scripts/build-artifact.mjs   # dist/artifact.html を生成
```
